# BaekjoonHub (스터디용) 설치 가이드

이 확장 프로그램은 Chrome 웹 스토어 정식 버전이 아닌 **커스텀 버전**입니다. 아래 방법으로 설치해 주세요.

---

## 준비물

- **Chrome 브라우저** (또는 Chromium 기반 브라우저)
- **dist 폴더** (운영자에게 받은 확장 프로그램 파일)
  - `dist` 폴더 전체가 필요합니다. zip으로 압축되어 있다면 **압축을 풀어** 사용하세요.

---

## 1단계: dist 폴더 받기

운영자에게 다음 중 하나를 받습니다.

- **방법 A**: `dist` 폴더가 들어 있는 **zip 파일** → 받은 뒤 원하는 위치에 압축 해제
- **방법 B**: GitHub 등에서 `dist` 폴더 직접 다운로드

> 예: `BaekjoonHub-custom-dist.zip`을 받았다면, `다운로드` 폴더 등에 압축을 풀어 `dist` 폴더가 보이도록 해 주세요.

---

## 2단계: Chrome에 확장 프로그램 설치

1. Chrome 주소창에 `chrome://extensions/` 입력 후 Enter
2. 오른쪽 상단 **개발자 모드** 스위치를 **켜기**
3. **압축해제된 확장 프로그램을 로드합니다** 버튼 클릭
4. **dist 폴더**를 선택
   - `dist` 폴더 **안**이 아니라, `dist` 폴더 **자체**를 선택해야 합니다
   - 예: `다운로드/BaekjoonHub-custom/dist` → 이 `dist` 폴더 선택
5. 목록에 "백준허브(BaekjoonHub)"가 나타나면 설치 완료

> **참고**: "폴더 선택" 창에서 `dist`라는 이름의 폴더를 선택해야 합니다. 그 안의 파일이 아니라 폴더 자체를 선택하세요.

---

## 3단계: GitHub 연동

1. Chrome 우측 상단 **확장 프로그램 아이콘**(퍼즐 모양) 클릭
2. **백준허브** 선택 → **Settings** 클릭
3. **Authorize with GitHub** 버튼 클릭
4. GitHub 로그인 후 **권한 승인** 화면에서:
   - **조직(Organization) 접근** 요청이 뜨면 **승인** 선택
   - "Request" 또는 "Grant" 버튼 클릭
5. 인증이 끝나면 설정 화면으로 돌아옵니다

---

## 4단계: 저장소 연결

1. **저장소 옵션**에서 선택:
   - **기존 저장소 연결**: 드롭다운에서 본인 저장소 선택
     - 조직 저장소는 `저장소명 (조직명)` 형태로 표시됩니다
   - **새 저장소 생성**: `조직명/저장소명` 형식으로 입력 (예: `my-study/haru-ps`)
2. **연결하기** 버튼 클릭
3. 다시 한 번 GitHub 인증이 필요하면 진행
4. 연결 완료 후 **기본 설정**에서 자동 업로드 등 옵션 확인

---

## 5단계: 사용하기

- **백준**(acmicpc.net), **프로그래머스**, **SW Expert Academy**에서 문제를 풀고 정답을 맞추면
- 자동으로 연결한 GitHub 저장소에 코드가 업로드됩니다.

## 자주 묻는 질문

### Q. "개발자 모드로 로드된 확장 프로그램" 경고가 뜹니다
**A.** 이 확장 프로그램은 정식 스토어 버전이 아니라서 나오는 메시지입니다. **무시**하고 사용하셔도 됩니다.

### Q. 조직 저장소가 목록에 안 보여요
**A.** GitHub 인증 시 조직 접근 권한을 승인했는지 확인해 주세요.  
또한 조직 관리자(운영자)가 **조직 설정 → Third-party access**에서 이 OAuth 앱을 승인해야 합니다.

### Q. dist 폴더를 옮기면 어떻게 되나요?
**A.** 폴더를 옮기면 확장 프로그램이 동작하지 않을 수 있습니다.  
다시 `chrome://extensions/`에서 해당 확장 프로그램을 **제거**한 뒤, 새 위치의 dist 폴더를 다시 로드해 주세요.

### Q. 업데이트된 버전을 받았어요
**A.** 새 dist 폴더로 교체한 뒤, `chrome://extensions/` 페이지에서 백준허브 카드의 **새로고침(🔄)** 버튼을 눌러 주세요.

---

## 문제가 생겼을 때

- **저장소 연결이 안 됨**: GitHub에서 해당 조직/저장소 접근 권한이 있는지 확인
- **업로드가 안 됨**: 설정에서 저장소가 제대로 연결되었는지, 자동 업로드가 켜져 있는지 확인
- **403 에러**: 조직 관리자에게 OAuth 앱 승인 요청

추가 문의는 스터디 운영자에게 연락해 주세요.

---

## [운영자용] dist 배포 준비

스터디원에게 배포할 때는 `dist` 폴더를 zip으로 압축해 전달하면 됩니다.

```bash
# 프로젝트 폴더에서
npm run build
zip -r BaekjoonHub-custom-dist.zip dist
```

생성된 `BaekjoonHub-custom-dist.zip`을 스터디원에게 전달합니다.  
받은 사람이 압축을 풀면 `dist` 폴더가 생기며, 이 가이드 2단계에서 그 `dist` 폴더를 선택하면 됩니다.
